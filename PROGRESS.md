  6. **Pulled the actual network evidence this time** (`browser_network_requests` filtered to `turnstile|challenges`): the flow does a `POST .../challenge-platform/h/b/fo/...` (200 OK) then a `GET .../challenge-platform/h/b/pat/...` which returns **`401`** with response header:
     `www-authenticate: PrivateToken challenge="...", token-key="...", ...` (repeated for 3 different issuers: `pat-issuer.cloudflare.com`, `sat.pat-issuer.cloudflare.com`, `pp-issuer-production.research.cloudflare.com`), `cf-ray: a1dfccd50b062757-FRA` (and a second occurrence `cf-ray` ending `-FRA` — confirms egress geolocates to Frankfurt/Germany, consistent with `data-country="DE"` seen in the Odoo page's own HTML attributes; note a **prior session's timezone spoof to `America/New_York` was itself a geo-inconsistency** that may have made things worse, though this session made no timezone/locale changes and still failed identically, so geo-consistency alone does not fix it).
  7. **This `pat` 401 + `WWW-Authenticate: PrivateToken` is the real, conclusive root cause: Cloudflare is gating this Turnstile challenge behind a Private Access Token (PAT) check** (an actual W3C/IETF Privacy Pass-family mechanism — see `draft-ietf-privacypass-*`). A PAT is issued by an OS/hardware-level attester (e.g. Apple's on real Apple devices via iCloud, or equivalent device-attestation infra on Android/ChromeOS/certain enrolled browsers) that cryptographically vouches "this request comes from a real, unmodified consumer device," independent of anything observable or spoofable from JavaScript, the CDP protocol, or browser UA/fingerprint. **A headless (or even headful) Chromium running inside a Linux sandbox/VM has no such attester and structurally cannot obtain a valid PAT, no matter how well the UA/platform/`window.chrome`/plugins/timezone/mouse-behavior fingerprints are spoofed.** This supersedes and sharpens the earlier "SwiftShader/no-GPU" theory from prior attempts — the no-GPU/software-rendering angle may still contribute to a *separate* browser-fingerprint signal Cloudflare also checks, but the PAT 401 shown here is a distinct, harder, non-spoofable gate that fully explains all 5 consecutive failures on its own.
